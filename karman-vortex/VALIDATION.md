# 已保存的运行核对

2026-10-23，默认 Re=150 的二维圆柱绕流。以下结果来自实际运行时的 GPU 场回读、尾流横向速度探针及交互观察；本次整理与上传未重新启动仿真。

## 场与脱涡周期

| 项目 | 初始网格 | 放大后的加密网格 | 缩回全域后的网格 |
|---|---:|---:|---:|
| 网格 | 1536×512 | 3072×1024 | 1536×512 |
| 圆柱直径 / 单元 | 64 | 128 | 64 |
| 场扫描时刻 tU∞/D | 64.1200 | 257.4950 | 281.2600 |
| 扫描流体值均有限 | 是 | 是 | 是 |
| 密度范围 | 0.988872–1.009307 | 0.988187–1.009501 | 0.987562–1.009459 |
| 最大速度 / U∞ | 1.4863 | 1.5037 | 1.4830 |
| 最大局部 Mach 数 | 0.1802 | 0.1823 | 0.1798 |
| 探针完整周期数 | 85 | 3 | 暂停，无新增周期 |
| 探针估计 St=fD/U∞ | 0.20136 | 0.20103 | — |

探针位于圆柱中心下游 4D、中心线上，以横向速度从负到正的过零间隔估计周期。扫描覆盖域内流体单元，排除最外层单元与圆柱实体。场扫描时刻与探针统计结束时刻不同，完整数值见 [初始网格摘要](validation/default.json)、[加密摘要](validation/refined.json) 和 [回落摘要](validation/coarsened.json)。

加密结果由当前尾流插值续算，只有 3 个探针周期，不是从独立初值重新运行的对照。两个频率接近不能当作网格收敛证据；有限域与边界条件也会影响频率。

## 缩放与连续性

- 放大到 3.375× 时，求解网格从 1536×512 加密到 3072×1024；当前尾流与正、负涡量均保留。
- 暂停后从约 5.1× 返回全域，网格回落到 1536×512；界面前后均显示 tU∞/D≈281.3，回落后的内部时间为 281.259999999961。
- 已观察放大、方向键平移、恢复全域、暂停与继续；滚轮定位缩放及鼠标拖拽平移的操作说明见 [README](README.md)。
- 3072×1024 网格在 NVIDIA Blackwell 适配器上的一次界面观察约为 76 FPS、7631 MLUPS，含绘制与可选回读。这是当时的实测显示值，不是独立性能基准或其他设备的性能承诺。
