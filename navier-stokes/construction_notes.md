# 论文构造与当前实现对应

阅读范围：按用户要求聚焦如何构造流场，省略证明机制与全文翻译。来源为 OpenAI《FINITE TIME BLOWUP FOR NAVIER–STOKES》，本地 PDF 共 166 页。下述公式是实现对应说明，具体定义以原文为准。

1. 第 24–25 页，式 (4.1)–(4.6)：设置 h、A=1/2+h、D=1/2−h，以 τ=1−t、q−z²q^(2h)=τ、η=z/q^D、X=r²/(2q) 建立内区坐标。实现通过单调根求解恢复 q。
2. 第 26 页，式 (4.7)：通过轴向廓线 U 及其径向平均恢复径向速度系数 V0，满足散度约束；径向压力由旋转廓线决定。
3. 第 27 页，式 (4.13)，以及第 144–145 页式 (B.1)、(B.3)：在旋转变量 F 中整理径向廓线方程，通过 η 的解析导数 jet 递推径向 Taylor 系数。代码取有限阶 14 阶，并非论文的完整解析构造与参数选择。
4. 用 q、F、U、V0 恢复笛卡尔速度与压力。在每个时刻以该速度进行真实物理时间的粒子积分；瞬时流线与历史随流轨迹分别绘制。

当前数值选择 h=0.005、λ=8、σ=0.3、j0=0.02；轴向 U(0,η)=4η+j0。旋转轴数据通过 ζ* 的积分形成，并在局部区间归一化。示例压力与有限区间归一化属于当前可视化的选择，不可据此声称满足论文完整爆破解条件。

文件对应：`src/profile.rs` 为廓线、坐标恢复与轨迹积分；`src/main.rs` 为 CPU 帧计算和本地 HTTP 服务；`index.html` 为显示与录制。

修复说明：中央厚层的显示范围与上下排出通道的范围分别取 0.4√τ 和 0.95√τ。两者都使用原速度场，没有轴向压缩、镜像下层或人为添加旋转速度。
