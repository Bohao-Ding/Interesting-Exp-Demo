# 理想加速度模型数据 / Ideal-Acceleration Model Data

本目录保存即时加速度伺服模型下的三摆切换与延迟数据。该模型将指令加速度直接施加到滑块，数据应按这一执行器假设解读。

This directory contains pendulum-transition and latency data for an instantaneous acceleration-servo model. Acceleration commands act directly on the cart; interpret these records under that actuator assumption.

带电机延迟与一阶响应的模型参数和物理验证分别见 [parameters.json](../../parameters.json) 与 [physics.json](../physics.json)。

Parameters and physics checks for the model with motor delay and first-order response are available in [parameters.json](../../parameters.json) and [physics.json](../physics.json).
