# 三维机翼流场与数值检查

以下为 NVIDIA GeForce RTX 5070 Ti、WebGPU 环境中的记录，包含流场采样、解析剪切波检查和存储精度对照。

## FP32 流场

[流场数据](validation/standard-fp32.json)采用 NASA WING01 全翼、两片翼刀和四片扰流板，迎角 8°、`Re_MAC=2000`、`Cs=0.14`。

| 项目 | 记录值 |
|---|---:|
| 网格 | 240×224×96，5,160,960 单元 |
| 推进步数 | 23,448 |
| 对流时间 `tU∞/MAC` | 79.78 |
| 全场数值 | 有限 |
| 密度范围 | 0.99312–1.01000 |
| 平均密度 | 0.999952 |
| 最高局部 Mach 数 | 0.156 |
| 瞬时 `CL` | 0.290 |
| 瞬时 `CD` | 0.210 |

四个近壁探针的上表面 `Cp` 约为 −0.29 至 −0.36，下表面约为 +0.10 至 +0.18。下游 `x/c_root=2.3` 两侧观察窗的环量约为 +0.0373 和 −0.0189，以 `U∞c_root` 归一化；流向涡量峰值约为 +3.92 和 −5.02。

观察窗包含主涡与次生涡，环量按整个窗口积分。气动力为瞬时值。这些数据用于描述压力差、升力及近尾迹的空间结构。

## 解析与边界检查

- 无机翼的均匀来流在同类风洞边界下推进 104 步，最大展向速度约 `8.5×10⁻⁶ U∞`，最大密度偏差约 `3.8×10⁻⁶`。
- 周期网格 `32×24×24` 上取格子黏性 0.05、关闭亚网格黏性，剪切波推进 256 步后，与 `A(t)=A₀ exp(−νk²t)` 的速度扰动相对 L2 误差约为 0.76%。

这两项分别检查均匀来流保持与黏性衰减。机翼计算的定量精度还取决于曲面边界、网格和近壁分辨率。

## 存储精度

[FP16 存储数据](validation/mixed-precision-rejected.json)采用缩放偏移分布函数和 FP32 运算。在该记录的构型下，与 FP32 对照推进 1,024 步后，速度分量 RMS 差为 `0.0655 U∞`，瞬时 `CL` 分别约为 0.414 和 0.489，压力系数也存在偏移。因此压力与气动力分析使用 FP32。

## 网格与图像

精细网格为 `360×336×144`，共 17,418,240 单元。平均气动弦约占 31 格，翼尖弦长约占 12 格；局部结构的解析程度应按这些尺度判断。
